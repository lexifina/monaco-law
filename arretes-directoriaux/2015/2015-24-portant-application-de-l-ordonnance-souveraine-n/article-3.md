# Article 3

Les tarifs du droit pour frais divers institués par la loi n° 1.060 susvisée et désignés à l'article 4 de l'ordonnance souveraine n° 8.043, modifiée, sont fixés comme suit :

1°) pour toute formalité mentionnée à l'article précédent, un droit de pagination de 0,30 euro(s) par page ;

2°) pour tout usage d'un procédé de photocopie, un droit de service rendu de 0,30 euro(s) par page ;

3°) pour toute lettre expédiée par le greffe général, un droit de frais de poste au tarif d'affranchissement ;

4°) pour tout usage d'un support numérique, un droit supplémentaire de frais de matériel de :

- 1 DVD 4 Go : 0,70 euro(s) ;

- 1 CD 650 Mo : 0,50 euro(s) ;

- Clé USB 4 Go : 5,50 euro(s) ;

- Clé USB 8 Go : 6,00 euro(s) ;

- Clé USB 16 Go : 15,00 euro(s) ;

- Clé USB 32 Go : 28,00 euro(s) ;

- Clé USB 64 Go : 30,00 euro(s) ;

- Clé USB 128 Go : 49,00 euro(s).
