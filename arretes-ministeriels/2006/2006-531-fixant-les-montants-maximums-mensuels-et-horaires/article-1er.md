# Article 1er

Les montants maximums mensuels et horaires des allocations familiales sont fixés ainsi qu'il suit pour l'exercice 2006-2007 :

- pour les enfants de moins de trois ans :

a ) montant mensuel maximum : 124,30 Euros

b ) taux horaire : 0,86 Euros

- pour les enfants âgés de trois à six ans :

a ) montant mensuel maximum :186,50 Euros

b ) taux horaire :1,29 Euros

pour les enfants âgés de six à dix ans :

a ) montant mensuel maximum :223,80 Euros

b ) taux horaire :1,54 Euros

- pour les enfants âgés de plus de dix ans :

a ) montant mensuel maximum :261,10 Euros

b ) taux horaire :1,80 Euros
