1. Liste des corps :

- Adjoint Administratif ;

- Agent de Maîtrise ;

- Agent des Services Hospitaliers Qualifié ;

- Aide-Soignant ;

- Aide de Pharmacie ;

- Auxiliaire Puéricultrice ;

- Conducteur Ambulancier ;

- Dessinateur ;

- Personnels ouvriers : Agent d'Entretien Qualifié, Ouvrier Professionnel Qualifié, Maître Ouvrier ;

- Secrétaire médicale.
