# Article 1er

I à XIII Voir les articles 1er, 5, 5 bis, 6, 15, 23, 26, 29, 35, 37, 40, 41 et 56 bis du Code des taxes sur le chiffre d'affaires.

XIV - L'article 64 du même code est abrogé.

XV - L'article 75 du même code est abrogé.

XVI à XVIII Voir les articles 88, 108 et 118 du Code des taxes sur le chiffre d'affaires.
