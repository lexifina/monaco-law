# Article 5

Le Code des taxes sur le chiffre d'affaires est ainsi modifié :

I Voir les articles 7, 18 et 93 B du Code des taxes.

II Voir l'article 29 du Code des taxes.

III Voir l'article 50-A du Code des taxes.

IV Voir l'article 65 du Code des taxes.

V Voir l'article 93 du Code des taxes.

VI.- Les II et V entrent en vigueur à compter du 1er janvier 2018.
