# Article A-168

Les dispositions de l'article 49 du code sont rendues applicables aux personnes ou sociétés mentionnées à l'article 63 de ce code ou susceptibles de bénéficier des dispositions prévues :

- au 8° du 4 de l'article 23 du code ;

- à l'article 48 du même code lorsqu'elles réalisent des exportations, des livraisons exonérées en vertu du I de l'article 31 dudit code ou des livraisons dont le lieu est situé sur le territoire d'un État membre de l'Union européenne autre que la France en application de l'article 7 du code précité ;

- à l'article 50 A du même code.
