# Article 856

Les sujets monégasques, qui se trouvent en pays étranger, peuvent y faire leurs dispositions testamentaires, soit par acte sous signature privée, conformément à l'article 835, soit par acte authentique reçu par un agent diplomatique ou consulaire du Prince, soit dans les formes usitées dans le pays pour les actes de dernière volonté.

Le dépôt des testaments mystiques sera également reçu dans les chancelleries diplomatiques et consulaires.
