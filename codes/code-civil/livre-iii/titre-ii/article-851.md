# Article 851

Les testaments faits sur mer, dans le cours d'un voyage, pourront être reçus à bord, par le capitaine, maître ou patron, ou par ceux qui les remplacent, et, pour les testaments de ces derniers, par ceux qui viennent après eux dans l'ordre du service.

Ces testaments doivent être reçus en présence de deux témoins, en double original.

Les dispositions ci-dessus seront communes aux testaments faits par les simples passagers, qui ne feront point partie de l'équipage.
