# Article L. 522-43

Nonobstant toute clause contraire, les actions nées du contrat de transport de marchandises peuvent être portées devant la juridiction monégasque, si le chargement ou le déchargement ont été effectués à Monaco. Elles peuvent également être portées devant la juridiction monégasque si celle-ci est compétente selon les règles du droit commun, ou si elle a été choisie par les parties.
