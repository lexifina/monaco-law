# Article L. 311-13

Dans chacun des cas prévus par les articles précédents, lorsqu'il y a récidive, outre l'application de l'article 40 du Code pénal, le maximum de l'amende prévue au chiffre 3 de l'article 26 dudit code est prononcé et l'interdiction de commander un navire peut être ordonnée à titre définitif.
