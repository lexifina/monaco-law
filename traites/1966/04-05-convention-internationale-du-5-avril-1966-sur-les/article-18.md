# Article 18

1) Les certificats sont établis dans la langue ou les langues officielles de l'État qui les délivre. Si la langue utilisée n'est ni l'anglais ni le français, le texte comprend une traduction dans l'une de ces langues.

2) Les certificats sont conformes aux modèles figurant à l'Annexe III. La disposition typographique de chaque modèle de certificat est exactement reproduite dans tout certificat délivré ou dans toute copie certifiée conforme.
